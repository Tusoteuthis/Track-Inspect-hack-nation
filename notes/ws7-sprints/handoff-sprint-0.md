## Decisions made
- **vitest 4.1, not 5.** vitest 5 needs `@types/node` ≥ 22. Using 4.1 avoided bumping the shared `@types/node@^20` that WS3 also depends on. The file name and script match the WS3 Sprint 0 prompt (`vitest.config.ts`, `"test": "vitest run"`), so a later merge is a small conflict. The default environment is `node`; component tests opt in with `// @vitest-environment jsdom`, which keeps WS3's node tests working.
- **Playwright on port 3100**, not 3000, so it never collides with other agents' dev servers.
- **New `invalid` render state.** The prompt listed resolved, ambiguous, unresolved and frame mismatch. Coordinates outside [0,1] or with zero size are now also refused, with an explanation.
- **Aspect-preserving focus crop.** The focus crop uses the same normalized span on both axes. The first version followed the region's shape and made tall, unreadable views (seen in a screenshot). The region label moves inside the outline near the top edge.
- **Placeholder pages already load data.** Each one loads its view through `DataSource` (not static text), which proves the wiring and makes the banner data-driven.
- **Constitution untouched.** `.specify/memory/constitution.md` is still the template; WS3 Sprint 0 owns it. The constitution check in `plan.md` used the sprint rules B2 instead.
- **Branch naming.** The team convention set by WS3 is `worktree-wsNN-sprint-N`. This sprint used `ws7-sprint-0` as the WS7 prompts said. Align the WS7 prompts/how-to if the team wants one convention.
